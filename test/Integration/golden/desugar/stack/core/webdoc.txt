            , cgcDoc = Just "Marks an annotation as one the webdocs offer as a page of its own, rather than one only written
              into a program beside the thing it is about. A reader is offered these by name — in the search
              box, without having to know they exist — so what is marked here is what there is to find, and
              an annotation added below is found by marking it and nothing else.
              What is left unmarked is as much of what this says as what is marked, since a reader offered a
              page they have no use for is a reader reading past it. Three kinds are left out. A display of
              whatever it is written on ([#md], [#print], [#test]) is not a page but part of one, and has
              nothing to show asked for on its own. A display of the doc server's own furniture ([#sidebar],
              [#search]) is already on the reader's screen, so offering it in the box it is drawn in says
              nothing. And a page about one program rather than about the pages there are ([#typeInfer]) has
              to be pointed at that program to mean anything, so it belongs where a page is already in hand
              rather than in a box offering the same thing wherever it is opened from.
              The last of those is about what the page says rather than about which program it is of, so a
              page about a program which still says something of every page there is belongs in the box.
              [#prgmGraph] is the case: pointed at a program it draws that program, and pointed at nothing it
              draws which pages the doc server holds and how they reach one another, which is worth opening
              from anywhere.
              Membership says the annotation is a page, not that it can be written with no argument. What can
              be offered without a reader typing anything is worked out from the declaration: an annotation
              taking no arguments is offered once, and one whose arguments are all sealed classes is offered
              once per combination of their members. An annotation taking a [String] — a type name, a
              function to run — names something only the reader knows, so marking it offers nothing until
              there is somewhere to type that in."
            }
