                `lcm(input= ..., page= ...)` where it is written ([/Catln/pageAt])." }
            )
        , /Catln/#md
            ( Value /text= CStr
                { csValue = "[lcm] calls [lcmPrompt] with the page it was handed, as here. A page with nothing written on
                it is shown as nothing, so what is asked is the question alone." }
            )
        , /Catln/#print
            ( Value /p= lcmPrompt
                ( Value input= CStr
                    { csValue = "What is on this page?" }
                )
                ( Value page= /Catln/RawPrgm( Value imports= Value /Data/List/Nil )( Value statements= Value /Data/List/Nil ) )
            )
            ( Value /result= CStr
                { csValue = "
                What is on this page?" }
            )
        , /Catln/#md
            ( Value /text= CStr
                { csValue = "## Asking about a page from the page
                A question about a page can be written on the page itself, as `q> ` and then the question. It
                is a [#q], and is asked by `catln process`, which writes the reply under the question as the
                `>>>` lines of its [result], the way `catln test --update` writes what a `> expr` prints. A
                question with a reply is not asked again; its `>>>` lines are removed to ask it again." }
            )
        , /Catln/#md
            ( Value /text= CStr
                { csValue = "## The request" }
            )
        , /Catln/#print
            ( Value /p= llmRequest
                ( Value model= CStr
                    { csValue = "m" }
                )
                ( Value input= CStr
                    { csValue = "Say "hi"" }
                )
            )
            ( Value /result= CStr
                { csValue = "{"model":"m","messages":[{"role":"user","content":"Say \"hi\""}]}" }
            )
        , /Catln/#md
            ( Value /text= CStr
                { csValue = "## The reply
                The reply is the text at `choices[0].message.content` of the response, read one step at a
                time. Each step answers [/Data/Maybe/Nothing] where the part it reads is not there, and the
                steps after it pass that on." }
            )
        , /Catln/#print
            ( Value /p= /operator==
                ( Value /l= llmReply
                    ( Value response= /Data/jsonParse
                        ( Value text= CStr
                            { csValue = "{"choices": [{"message": {"role": "assistant", "content": "Hello!"}}]}" }
                        )
                    )
                )
                ( Value /r= /Data/Maybe/Some
                    ( Value value= CStr
                        { csValue = "Hello!" }
                    )
                )
            )
            ( Value /result= CStr
                { csValue = "True" }
            )
        , /Catln/#print
            ( Value /p= /operator==
                ( Value /l= llmReply
                    ( Value response= /Data/jsonParse
                        ( Value text= CStr
                            { csValue = "{"error": "no"}" }
                        )
                    )
                )( Value /r= Value /Data/Maybe/Nothing )
            )
            ( Value /result= CStr
                { csValue = "True" }
            )
        ]
