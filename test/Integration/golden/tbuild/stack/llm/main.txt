                  [llm] sends a prompt to a language model and answers with its reply. It speaks the chat
                  completions API that OpenAI serves and that most other model servers copy, so where it sends is
                  configured rather than fixed, by environment variables:
                  - `OPENAI_BASE_URL` is the address of the API, up to and not including `/chat/completions`:
                    `https://api.openai.com/v1`, or `http://localhost:11434/v1` for a model served locally.
                  - `OPENAI_MODEL` is the model to ask.
                  - `OPENAI_API_KEY` is the key to ask with, sent as a bearer token. It may be left unset, for a
                    server that asks for none.
                  It is a method of [/Catln/IO] because everything it does reaches outside the program: it reads
                  the environment and it sends a request.
                  This is not part of the standard library. A program which asks no model has no use for it, and
                  one that does writes `import "llm"`.
                  It is written in parts, each a page of this directory:
                  - @llm/err.ct@ is [LlmErr], why a model gave no reply.
                  - @llm/api.ct@ is [llm] itself: the request it sends, and how the reply is read from the
                    response.
                  - @llm/show.ct@ is what a model is shown of a value ([LlmShow]) and of a page ([showPage]).
                  - @llm/lcm.ct@ is [lcm], asking with the page the call is written on.
                  - @llm/q.ct@ is [#q], a question written on a page and asked by `catln process`.
                  - @llm/typed.ct@ is [tllm] and [tlcm], asking for a value of a type rather than for text."
