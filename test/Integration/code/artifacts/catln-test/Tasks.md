A note may hold tasks, written as markdown checkboxes.

- [ ] Read [[Welcome]]
- [x] Write this note
  Which is written under the task rather than beside it, so it is a comment of the task.

  It goes on for as long as it is indented.
- [ ] Plan the rest
  - [ ] A checkbox indented deeper is a task of its own

Anything written after them is the note again.

```
- [ ] A checkbox inside code is writing about a task rather than making one
```
